# Ore is for Mining (Factorio mod)

Factorio 2.1 mod (Space Age optional): only mining drills, belts, underground belts, splitters, loaders, inserters, beacons, power poles and pipes can be built on resource patches (ores and fluids like crude oil).

## How it works
- `data.lua` defines the `opr_resource` collision layer and the public `ore_is_for_mining` table other mods use to allow/block entities.
- `data-final-fixes.lua` adds that layer to resources and to every `player-creation` entity whose type isn't allowed, so the engine blocks placement (ghosts and blueprints included). Vehicles, trains, elevated rails and ghosts are never touched.
- Rules are type-based so modded entities are covered automatically.
- Startup settings in `settings.lua`, text in `locale/en/locale.cfg` (setting names are `opr-*`).

## Testing
- `tests/run.sh` runs all scenarios against real prototype data from wube/factorio-data (2.0.77 and 2.1.20 by default, cached in `tests/.factorio-data/`).
- Add scenarios in `tests/scenario.lua` and list them in `tests/run.sh`.
- Requires Lua 5.2 (`lua`, `luac`), which matches the game's Lua version.

## Notes
- The game is installed on Windows. Mods folder: `C:\Users\Cristian\AppData\Roaming\Factorio\mods` (the folder name must match `name` in `info.json`).
- Release files: `changelog.txt` must keep Factorio's strict format (99-dash separator lines, 2-space category indent, 4-space `- ` entries). `README.md` is the mod portal description.
- `thumbnail.png` is generated by `tools/make_thumbnail.py` (standard library only) from the game's own sprites; it reads them from the Windows install at `D:\SteamLibrary\steamapps\common\Factorio\data` (or a path given as the first argument). `tests/` and `tools/` don't belong in the release zip.

## Releasing
- `python3 tools/release.py` validates (info.json, changelog, tests) and builds `dist/<name>_<version>.zip`. It never uploads without `--publish`.
- `--publish` needs `FACTORIO_API_KEY` in the environment. It publishes a new mod or uploads a release, then syncs the portal page from `README.md`. Never publish unless the user explicitly asks.
- For a new release: bump `version` in `info.json` and add a matching entry at the top of `changelog.txt`.
